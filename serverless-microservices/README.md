## About the Book

**Practical Serverless and Microservices with C#** is a hands-on guide for designing, building, and deploying serverless and microservices-based solutions with C#. The book focuses on practical examples covering real-world scenarios, using industry-standard tools and cloud platforms.

---

## Getting Started

To get started with the code samples in this repository:

1. Clone the repository:
   ```bash
   git clone https://github.com/PacktPublishing/Practical-Serverless-and-Microservices-with-Csharp.git
   ```
2. Navigate to the desired chapter folder.
3. Follow the instructions in the respective `README.md` or project files.

---

## Project Structure

- **ch01**: Introduction to serverless and microservices with basic examples.
- **ch03**: Onion Architecture with complete and partial implementations.
- **ch04**: Microservices for auditing, car holding, and route planning.
- **ch05**: Azure Functions examples including Blob Storage and Timer Triggers.
- **ch06**: IoT-related services like Car Simulator and Device Simulation.
- **ch07**: Advanced car-sharing microservices.
- **ch08**: Kubernetes configurations and deployment examples.
- **ch10**: Security implementations including JWT and OAuth 2.0.
- **ch11**: Comprehensive car-sharing solution with UI and microservices.
- **ch12**: Final car-sharing project with shared messages and domain layers.

## Prerequisites

- .NET SDK 8.0 or later
- Azure Functions Core Tools
- Docker (for containerized examples)
- Kubernetes (for deployment examples in Chapter 8)
- Visual Studio or VS Code

---

## How to Run the Examples

1. Ensure all prerequisites are installed.
2. Navigate to the desired chapter folder.
3. Build the project using:
   ```bash
   dotnet build
   ```
4. Run the project using:
   ```bash
   dotnet run
   ```
5. For Azure Functions, use:
   ```bash
   func start
   ```
